# Phase E1 — Transmission and Rough Glass Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make transmissive materials render as glass inside the RTX path tracer — GGX refraction with real dielectric Fresnel, total internal reflection, thin-walled and volumetric paths, and Beer-Lambert absorption.

**Architecture:** Reflection and transmission become one dielectric microfacet closure that splits internally on a Fresnel-weighted probability, matching Cycles' `bsdf_microfacet_sample`. The closure is dispatched only when `transmission > 0`, so opaque materials keep running today's `sampleSpecularMicrofacet` instruction-for-instruction. Refracted rays get back-face visibility via a payload flag read by raygen; absorption is applied at the exit hit using `gl_HitTEXT` as the internal path length, needing no medium stack.

**Tech Stack:** GLSL (Vulkan RT extensions), C++ (Godot 4.7 fork), SCons, doctest, GDScript gate scenes.

**Spec:** `docs/superpowers/specs/2026-08-19-transmission-rough-glass-design.md` — read §3 (decisions) and §11 (verified facts) before starting any task.

**Reference source:** Blender at `C:\Users\aiadmin\Desktop\blender_build\blender`. Cycles paths below are relative to `intern/cycles/`.

#include "core/math/math_funcs.h"

namespace TestPTTransmission {

// CPU mirrors of the transmission math in
// servers/rendering/renderer_rd/shaders/raytracing/brdf_inc.glsl.
// Ported from Blender Cycles: intern/cycles/kernel/closure/bsdf_util.h:47-108.
// These must stay textually identical to the GLSL modulo type names -- a drift
// makes this suite pass while the shader is wrong.

static float sqr(float x) {
	return x * x;
}

static float f0_from_ior(float p_ior) {
	return sqr((p_ior - 1.0f) / (p_ior + 1.0f));
}

static float ior_from_f0(float p_f0) {
	const float sqrt_f0 = Math::sqrt(CLAMP(p_f0, 0.0f, 0.99f));
	return (1.0f + sqrt_f0) / (1.0f - sqrt_f0);
}

// Returns reflectance; writes the cosine of the transmitted angle (negative,
// relative to the surface normal). Returns exactly 1.0 on total internal
// reflection, in which case r_cos_theta_t is left untouched and no transmitted
// direction exists.
static float fresnel_dielectric(float p_cos_theta_i, float p_eta, float *r_cos_theta_t) {
	const float eta_cos_theta_t_sq = sqr(p_eta) - (1.0f - sqr(p_cos_theta_i));
	if (eta_cos_theta_t_sq <= 0.0f) {
		return 1.0f; // Total internal reflection.
	}
	const float cos_theta_i = Math::abs(p_cos_theta_i);
	const float cos_theta_t = -Math::sqrt(eta_cos_theta_t_sq) / p_eta;
	if (r_cos_theta_t) {
		*r_cos_theta_t = cos_theta_t;
	}
	const float r_s = (cos_theta_i + p_eta * cos_theta_t) / (cos_theta_i - p_eta * cos_theta_t);
	const float r_p = (cos_theta_t + p_eta * cos_theta_i) / (p_eta * cos_theta_i - cos_theta_t);
	return (sqr(r_s) + sqr(r_p)) * 0.5f;
}

static Vector3 refract_angle(const Vector3 &p_incident, const Vector3 &p_normal, float p_cos_theta_t, float p_inv_eta) {
	return (p_inv_eta * p_normal.dot(p_incident) + p_cos_theta_t) * p_normal - p_inv_eta * p_incident;
}

TEST_CASE("[PathTracer][Transmission] F0 and IOR round-trip") {
	// Cycles bsdf_util.h:290-293. Glass at 1.5 is the canonical 4% dielectric,
	// and it is the value Godot's own specular default of 0.5 already produces
	// via specular_to_f0 (0.16 * 0.5^2 = 0.04). The two conventions coinciding

	CHECK(f0_from_ior(1.5f) == doctest::Approx(0.04f).epsilon(1e-6));
	CHECK(f0_from_ior(1.0f) == doctest::Approx(0.0f).epsilon(1e-9));

	// ior == 0.0 is LEGAL glTF (KHR_materials_ior permits it as a signal value)
	// and Phase D imports it without complaint. It must yield a fully reflective
	// surface, not a NaN.
	CHECK(f0_from_ior(0.0f) == doctest::Approx(1.0f).epsilon(1e-9));

	CHECK(ior_from_f0(f0_from_ior(1.5f)) == doctest::Approx(1.5f).epsilon(1e-4));
	CHECK(ior_from_f0(f0_from_ior(2.4f)) == doctest::Approx(2.4f).epsilon(1e-4));
}

TEST_CASE("[PathTracer][Transmission] Fresnel at normal incidence equals F0") {
	float cos_t = 0.0f;
	CHECK(fresnel_dielectric(1.0f, 1.5f, &cos_t) == doctest::Approx(0.04f).epsilon(1e-5));
	CHECK(cos_t == doctest::Approx(-1.0f).epsilon(1e-6));
}

TEST_CASE("[PathTracer][Transmission] Fresnel reaches 1 at grazing incidence") {
	float cos_t = 0.0f;
	CHECK(fresnel_dielectric(0.001f, 1.5f, &cos_t) > 0.99f);
}

TEST_CASE("[PathTracer][Transmission] Total internal reflection at and past critical angle") {
	// Exiting glass into air: eta = 1/1.5. Critical angle is asin(eta) = 41.81deg,
	// so cos(critical) = 0.745356. AT the critical angle eta_cos_theta_t_sq is
	// exactly zero and the <= 0 test must already fire -- an implementation using
	// < 0 would leak a zero-length transmitted direction here.
	const float eta = 1.0f / 1.5f;
	const float cos_critical = Math::cos(Math::asin(eta));
	float cos_t = -999.0f;

	CHECK(fresnel_dielectric(cos_critical, eta, &cos_t) == doctest::Approx(1.0f).epsilon(1e-5));
	CHECK(cos_t == -999.0f); // Untouched: no transmitted direction exists.

	// Past critical (shallower angle, smaller cosine) stays fully reflective.
	CHECK(fresnel_dielectric(cos_critical * 0.5f, eta, &cos_t) == doctest::Approx(1.0f).epsilon(1e-9));
	CHECK(cos_t == -999.0f);

	// Just inside critical still transmits.
	CHECK(fresnel_dielectric(cos_critical * 1.05f, eta, &cos_t) < 1.0f);
	CHECK(cos_t != -999.0f);
}

TEST_CASE("[PathTracer][Transmission] Refraction obeys Snell's law") {
	// Incident 45deg from the normal, entering glass (eta = 1.5).
	const Vector3 N = Vector3(0, 0, 1);
	const float cos_i = Math::cos(Math::deg_to_rad(45.0f));
	const float sin_i = Math::sin(Math::deg_to_rad(45.0f));
	const Vector3 wi = Vector3(sin_i, 0, cos_i); // Points AWAY from the surface.

	float cos_t = 0.0f;
	fresnel_dielectric(cos_i, 1.5f, &cos_t);
	const Vector3 wo = refract_angle(wi, N, cos_t, 1.0f / 1.5f);

	CHECK(wo.length() == doctest::Approx(1.0f).epsilon(1e-5));
	CHECK(wo.z < 0.0f); // Transmitted: below the surface.

	// Snell: sin(theta_t) = sin(theta_i) / eta.
	const float sin_t = Math::sqrt(wo.x * wo.x + wo.y * wo.y);
	CHECK(sin_t == doctest::Approx(sin_i / 1.5f).epsilon(1e-4));
}

	const Vector3 N = Vector3(0, 0, 1);
	const Vector3 wi = Vector3(0, 0, 1);
	float cos_t = 0.0f;
	fresnel_dielectric(1.0f, 1.5f, &cos_t);

	CHECK(wo.x == doctest::Approx(0.0f).epsilon(1e-6));
	CHECK(wo.y == doctest::Approx(0.0f).epsilon(1e-6));
	CHECK(wo.z == doctest::Approx(-1.0f).epsilon(1e-6));
}

```glsl
// -------------------------------------------------------------------------
//    Dielectric Fresnel and refraction (roadmap E1)
//
//    Ported from Blender Cycles, intern/cycles/kernel/closure/bsdf_util.h:47-108.
//    A C++ MIRROR of these four functions lives in
//    tests/servers/rendering/test_pt_transmission.cpp and is what the doctest
//    suite asserts against -- the suite does NOT execute this shader. Keep the
//    two textually identical modulo type names; a drift makes the tests pass
//    while this code is wrong.
//
//    Why not reuse the Schlick evalFresnel above: Schlick is parameterised on
//    F0 and has no eta, so it cannot express total internal reflection at all.
//    TIR here falls out of the SAME test that produces cos_theta_t, so the two
//    cannot drift out of sync.
// -------------------------------------------------------------------------

float F0_from_ior(float ior) {
	float t = (ior - 1.0f) / (ior + 1.0f);
	return t * t;
}

float ior_from_F0(float f0) {
	float sqrt_f0 = sqrt(clamp(f0, 0.0f, 0.99f));
	return (1.0f + sqrt_f0) / (1.0f - sqrt_f0);
}

// Returns reflectance for unpolarized light. Writes the cosine of the
// transmitted angle (NEGATIVE, relative to the surface normal).
//
// Returns exactly 1.0 on total internal reflection, leaving r_cos_theta_t
// untouched -- no transmitted direction exists in that case. The `<= 0.0`
// test is deliberate and load-bearing: AT the critical angle the discriminant
// is exactly zero, and a `< 0.0` test would leak a degenerate zero-length
// transmitted direction through.
//
// CALLER CONTRACT: do not compute 1.0 / eta before this returns. ior == 0.0 is
// legal glTF (KHR_materials_ior permits it as a signal value) and Phase D
// imports it without complaint; the TIR branch handles it correctly, but an
// eagerly-evaluated reciprocal would already be an infinity.
float fresnel_dielectric(float cos_theta_i, float eta, OUT_PARAMETER(float) r_cos_theta_t) {
	float eta_cos_theta_t_sq = eta * eta - (1.0f - cos_theta_i * cos_theta_i);
	if (eta_cos_theta_t_sq <= 0.0f) {
		return 1.0f; // Total internal reflection.
	}
	float ci = abs(cos_theta_i);
	float cos_theta_t = -sqrt(eta_cos_theta_t_sq) / eta;
	r_cos_theta_t = cos_theta_t;

	// Amplitudes of the reflected s- and p-polarised waves.
	float r_s = (ci + eta * cos_theta_t) / (ci - eta * cos_theta_t);
	float r_p = (cos_theta_t + eta * ci) / (eta * ci - cos_theta_t);

	// Squared amplitude gives the fraction of reflected energy.
	return (r_s * r_s + r_p * r_p) * 0.5f;
}

// `incident` points AWAY from the surface (toward the viewer), matching V.
// `cos_theta_t` is the negative cosine returned by fresnel_dielectric.
// `inv_eta` is 1.0 / eta.
float3 refract_angle(float3 incident, float3 normal, float cos_theta_t, float inv_eta) {
	return (inv_eta * dot(normal, incident) + cos_theta_t) * normal - inv_eta * incident;
}
```

// 0.16*specular^2 response curve substituted for Blender's 2*level.
static void resolve_f0(float p_ior, float p_specular, float p_specular_factor,
		const Vector3 &p_specular_tint, Vector3 *r_f0, float *r_eta) {
	const float f0_scalar = f0_from_ior(p_ior);
	Vector3 f0 = Vector3(f0_scalar, f0_scalar, f0_scalar) * p_specular_factor;
	f0.x *= p_specular_tint.x;
	f0.y *= p_specular_tint.y;
	f0.z *= p_specular_tint.z;

	// Godot's specular_to_f0 is 0.16*s^2, normalised against the 0.04 reference
	// so this factor is EXACTLY 1.0 at the 0.5 default. That exactness is what
	// makes an untouched material bit-identical to pre-E1.
	f0 *= 4.0f * p_specular * p_specular;

	*r_f0 = f0;
	// Cycles re-derives eta from the modified F0 so reflectance and refraction
	// cannot disagree (svm/closure.h:429-431). Only when the knob is off-default.
	const float lum = 0.2126f * f0.x + 0.7152f * f0.y + 0.0722f * f0.z;
	*r_eta = (p_specular != 0.5f) ? ior_from_f0(lum) : p_ior;
}

TEST_CASE("[PathTracer][Transmission] F0 arbitration is a no-op at every default") {
	Vector3 f0;
	float eta = 0.0f;
	resolve_f0(1.5f, 0.5f, 1.0f, Vector3(1, 1, 1), &f0, &eta);

	// 0.04 is what specular_to_f0(0.5) produced before E1. Bit-exactness here is
	// the whole no-pixel-change guarantee for untouched materials.
	CHECK(f0.x == doctest::Approx(0.04f).epsilon(1e-6));
	CHECK(f0.y == doctest::Approx(0.04f).epsilon(1e-6));
	CHECK(f0.z == doctest::Approx(0.04f).epsilon(1e-6));

}

- [ ] **Step 3: Add the split helper and the closure**

**The split is computed in two places** — inside the closure when sampling, and
inside `combinedPdf` when evaluating the density for MIS. Those two MUST return
the same number for the same inputs. If they drift, the MIS weights partition a
different integrand than the estimator evaluates, which is exactly the defect
class B2 shipped and C3 measured at +2.4%. So it is one function, called twice,
not two copies.

In `brdf_inc.glsl`, immediately after `sampleSpecularMicrofacet` (which ends
around `:915`), first insert the helper:

```glsl
// Fresnel-weighted reflect-vs-transmit split for a dielectric microfacet.
// Ported from Cycles bsdf_microfacet.h:844-851 and :299-305.
//
// SINGLE SOURCE OF TRUTH for the split. sampleDielectricMicrofacet uses it to
// CHOOSE a lobe; combinedPdf uses it to report that choice's DENSITY. Two
// copies that disagree would make every MIS weight on a transmissive surface
// describe a different integrand than the estimator evaluates. Do not inline
// a second copy.
//
// Returns pdf_reflect. Writes the remapped per-channel reflectance, the scalar
// transmittance, and the cosine of the transmitted angle (only meaningful when
// the return value is below 1.0 -- under TIR no transmitted direction exists
// and cos_theta_t is left untouched).
float dielectricFresnelSplit(float HdotV, float eta, float3 F0, float transmission, OUT_PARAMETER(float3) reflectance, OUT_PARAMETER(float) transmittance, OUT_PARAMETER(float) cos_theta_t) {
	float F_real = fresnel_dielectric(HdotV, eta, cos_theta_t);

	// Remap the real Fresnel curve onto the tinted [F0, 1] range -- Cycles'
	// generalized-Schlick "exponent < 0" branch (bsdf_microfacet.h:299-305).
	// This is how a tinted F0 (from specular_tint) coexists with a real Fresnel
	// term that TIR depends on: plain Schlick cannot express TIR, and plain
	// real Fresnel cannot carry the tint.
	float F0_real = F0_from_ior(eta);
	float s = saturate((F_real - F0_real) / max(1.0f - F0_real, 0.00001f));
	reflectance = lerp(F0, float3(1.0f, 1.0f, 1.0f), s);
	transmittance = (1.0f - F_real) * transmission;

	float avg_reflectance = dot(reflectance, float3(1.0f, 1.0f, 1.0f)) / 3.0f;
	float denom = avg_reflectance + transmittance;

	// The guard is LOAD-BEARING, not defensive. At eta == 1.0 with
	// transmission == 0, F_real is 0, reflectance is F0 == 0, transmittance is
	// 0, and the unguarded ratio is 0/0. sanitize_payload_value would silently
	// zero the resulting NaN and poison the pixel with no failing test. Falling
	// back to 1.0 routes the degenerate case down the reflective branch with a
	// zero weight, terminating the path cleanly.
	return (denom > 0.0f) ? (avg_reflectance / denom) : 1.0f;
}
```

Then, after it, the closure itself:

```glsl
// Dielectric microfacet closure: reflection AND transmission as one closure
// that splits internally on a Fresnel-weighted probability. Structure ported
// from Cycles bsdf_microfacet_sample (bsdf_microfacet.h:844-914).
//
// CALLED ONLY WHEN transmission > 0. An opaque material takes
// sampleSpecularMicrofacet above, unchanged. That dispatch is deliberate and
// load-bearing: the Fresnel remap below is NOT equal to that function's Schlick
// evalFresnel, so routing everything through here would change the reflectance
// of every specular surface in every existing scene. See spec section 4.2.
//
// Returns false when no usable direction was produced (TIR with no reflective
// energy, or a degenerate half-vector). Resulting weight includes the cosine
// term, matching sampleSpecularMicrofacet's convention.
bool sampleDielectricMicrofacet(float3 Vlocal, float alpha, float alphaSquared, float3 F0, float eta, float transmission, float3 u, OUT_PARAMETER(float3) Llocal, OUT_PARAMETER(float3) weight, OUT_PARAMETER(bool) isTransmit) {
	const float3 Nlocal = float3(0.0f, 0.0f, 1.0f);

	float3 Hlocal;
	if (alpha == 0.0f) {
		// Fast path for zero roughness, and it also prevents the NaNs a
		// division by zero would produce inside VNDF sampling.
		Hlocal = float3(0.0f, 0.0f, 1.0f);
	} else {
		Hlocal = sampleSpecularHalfVector(Vlocal, float2(alpha, alpha), u.xy);
	}

	float HdotV = dot(Hlocal, Vlocal);

	// cos_theta_t is only written when a transmitted direction exists; under
	// TIR the helper returns 1.0 and leaves it alone.
	float cos_theta_t = 0.0f;
	float3 reflectance;
	float transmittance;
	float pdf_reflect = dielectricFresnelSplit(HdotV, eta, F0, transmission,
			reflectance, transmittance, cos_theta_t);

	isTransmit = (u.z >= pdf_reflect);

	if (isTransmit) {
		// TIR returned F_real == 1.0, so transmittance is 0 and pdf_reflect is 1;
		// u.z < 1.0 always (rng_1d's divisor is 2^32 + 512), so this branch is
		// unreachable under TIR and cos_theta_t is guaranteed to have been written.
		Llocal = refract_angle(Vlocal, Hlocal, cos_theta_t, 1.0f / eta);
		float denom_t = 1.0f - pdf_reflect;
		if (denom_t <= 0.0f) {
			return false;
		}
		float NdotL = min(-0.00001f, dot(Nlocal, Llocal));
		float NdotV = max(0.00001f, min(1.0f, dot(Nlocal, Vlocal)));
		float NdotH = max(0.00001f, min(1.0f, dot(Nlocal, Hlocal)));
		float HdotL = max(0.00001f, min(1.0f, abs(dot(Hlocal, Llocal))));
		// NOTE: no evalMultiScatterApproximation here. It is derived for
		// reflection-only GGX and applying it to the transmitted lobe would add
		// energy its derivation does not cover, so this lobe is single-scatter
		// and slightly dark at high roughness. Cycles has the same limitation.
		weight = float3(transmittance, transmittance, transmittance) / denom_t *
				specularSampleWeight(alpha, alphaSquared, abs(NdotL), NdotV, HdotL, NdotH);
	} else {
		Llocal = reflect(-Vlocal, Hlocal);
		float HdotL = max(0.00001f, min(1.0f, dot(Hlocal, Llocal)));
		float NdotL = max(0.00001f, min(1.0f, dot(Nlocal, Llocal)));
		float NdotV = max(0.00001f, min(1.0f, dot(Nlocal, Vlocal)));
		float NdotH = max(0.00001f, min(1.0f, dot(Nlocal, Hlocal)));
#if MICROFACET_DISTRIBUTION == GGX
		float3 ms = evalMultiScatterApproximation(alpha, NdotV, F0);
#else
		float3 ms = float3(1.0f, 1.0f, 1.0f);
#endif
		weight = ms * (reflectance / pdf_reflect) *
				specularSampleWeight(alpha, alphaSquared, NdotL, NdotV, HdotL, NdotH);
	}

	return true;
}
```

   the struct, its default, and both raygen fill sites, so every step is now
   self-consistent read in isolation.
2. Task 5's `mirror_pdf_reflect` hardcoded `f0_from_ior(1.5f)` while accepting an
   arbitrary `F_real`, so it would silently mis-assert at any other IOR. Fixed by
   taking `p_eta` as a parameter.

**One defect found in the pre-flight scan and fixed by amendment.** The plan
originally inlined the Fresnel remap / `pdf_reflect` computation at three sites
and the F0 arbitration at two. Both are now single functions in `brdf_inc.glsl`
— `dielectricFresnelSplit` (Task 5) and `resolveDielectricF0` (Task 3) — called
from every site. This is not a style preference: the sampling density and the
`combinedPdf` density are the two halves of every MIS weight on a transmissive
surface, and a gate that validates its own copy of the arbitration proves
nothing about the renderer.

**One residual risk, not fixable from here.** The GLSL in Tasks 5 and 6 has been
read against its call sites but never compiled. `rotatePoint`, `invertRotation`,
`getRotationToZAxis`, `sampleSpecularHalfVector`, `specularSampleWeight` and
`luminance` are all used on the assumption that they are in scope at those points
with those signatures. The first implementer to build should expect to correct
one or two and should treat that as normal rather than as evidence the design is
wrong.

**Type consistency.** `sampleDielectricMicrofacet`'s signature is identical in Task 5's interface block and its code. `MaterialProperties` gains `float3 dielectricF0` (Task 2) and `float ior` (Task 5); `transmissivness` already exists and is populated in Task 6. `MaterialResult` gains six fields total — `transmission`, `ior`, `thickness`, `attenuation`, `specular_tint`, `specular_factor` — across Tasks 3 and its Step 5 amendment.
